# Voxlate v0.1.0-beta.1 · Windows 测试版

本地视频配音工具，支持英文／日文对白转为中文声音，方便逐句试听、校对和重配。

## 下载与开始

下载附件 **Voxlate-v0.1.0-beta.1-windows-x64.zip**，完整解压后运行 `voxlate.exe`。不需要预装 Python；`Source code` 是开发用源码。

首次打开 **资源配置 → 一键准备** 下载模型和环境；拖入视频，选择音轨及语言方向，点击 **一键导出**。也可以按识别、翻译、生成配音、导出视频四步校对。

## 主要功能

- Whisper v3、turbo、综合识别及独立 Qwen 识别选项；Hy-MT2 翻译与 IndexTTS 音色克隆。
- 原文／译文逐句试听，修改译文后只重配该句。
- 统一、逐句和分角色音色；角色自动分组后可手动修正。
- 局部波形手动分句，只重新处理新增或调整的句子。
- 多音轨选择、分步保存和配音缓存；未配音区间保留原音轨。

## 环境与限制

- 64 位 Windows，默认使用 NVIDIA CUDA 显卡；最低内存／显存尚未系统验证，建议先试短片。
- ZIP 不含 AI 模型和运行环境，首次需联网另下载数十 GB；视频处理在本地完成。
- 当前只支持英文／日文 → 简体中文，不支持六向互转，不保证嘴型同步。
- 自动识别、分句、翻译和角色分组可能有误，长视频与日语效果仍需更多测试。
- 默认导出立体声 AAC，不是无损音频；请保留原视频。
- 初版未做商业代码签名。请从本仓库下载，并按附件 `SHA256SUMS.txt` 校验。
