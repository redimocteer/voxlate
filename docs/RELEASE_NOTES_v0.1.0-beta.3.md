# Voxlate v0.1.0-beta.3 · 分句编辑与逐句配音

本版仍支持 **英文／日文 → 简体中文**，界面为中文。三语互转保留在开发分支，不包含在此安装包中。

## 主要变化

- 分离与自动分句独立执行；Qwen 支持续识别、续对齐，对时间存疑的对白保留原声，减少错误配音。
- 新增全片手动分句和局部微调：波形、小地图、视频预览、拖选时段、批量删除、撤销／重做及逐句翻译。仅处理改动的句子。
- 全文翻译可选“仅补全空白”或“全部重译”；全文配音可选“仅补全缺失”或“全部重配”。一键完成复用已有有效结果。
- 默认逐句音色；右击单句配音按钮可选择其他句子的原声音色，并保存该句选择。已有配音的播放按钮显示蓝色。
- 单句配音只准备所选句子的音频，避免先处理全片。翻译和配音模型可驻留复用，切换任务时互相释放，也可手动选择释放。
- 改善选取／舍弃响应、项目搬迁及退出处理；载入已有项目时显示状态，覆盖手动分句前简洁确认。

## 下载与更新

下载 **Voxlate-v0.1.0-beta.3-windows-x64.zip**，完整解压后运行 `voxlate.exe`，保留 `_internal` 文件夹；无需预装 Python。先退出旧程序，再运行新版，默认沿用原配置和模型。重要项目建议先备份，不必删除已有识别结果。

`SHA256SUMS.txt` 用于校验附件；`third-party-sources.zip` 是对应依赖源码，普通用户无需下载。程序包不含模型、外部推理环境或用户素材；下载模型前请阅读[来源与许可说明](https://github.com/redimocteer/voxlate/blob/main/docs/RESOURCE_DOWNLOADS.md)。

## 验证与限制

已进行自动回归、合成素材流程检查及打包程序启动检查。未完成全新电脑安装、最低显存和各类长片的系统验证；请先试短片。识别、时间边界、翻译及音色仍可能出错，需要试听校对；保留原声的保守策略可能漏配真实对白。

默认需要 NVIDIA CUDA 显卡和数十 GB 资源空间。问题请到 [Issues](https://github.com/redimocteer/voxlate/issues) 反馈，分享日志前删去私人路径、对白和凭据。
