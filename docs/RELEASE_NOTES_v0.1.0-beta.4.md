# Voxlate v0.1.0-beta.4 · 音色管理与灵活导出

本版支持 **英文／日文 → 简体中文**，界面为中文。三语互转仍在开发分支，不包含在此程序包中。

## 主要变化

- 新增外部音色：打开一段音频或视频作为参考；音色管理支持试听、导出参考音频。
- 选择主界面任意句子的时间、原文或译文后，可只翻译／配音所选句子，支持补缺或覆盖。
- 手动分句支持“仅应用分句”，先保存边界，之后翻译时自动补识别；取消未保存修改时提醒确认。局部微调取消原来的 10 句限制，与全片编辑共用上限。
- 导出时可确认将未配音或需重配的句子保留原声，其余有效配音照常使用。
- 重新分离前确认覆盖；失败或停止时保留原分离结果。修复 Windows 临时文件占用可能中断识别进度更新的问题。
- 统一音色管理图标与布局，更新使用说明和合成示例截图。

## 下载与更新

下载 **Voxlate-v0.1.0-beta.4-windows-x64.zip**，完整解压后运行 `voxlate.exe`，保留 `_internal` 文件夹；无需预装 Python。退出旧程序后运行新版，可沿用原配置和模型。修改重要项目之前，请备份视频旁的 `.voxlate` 文件夹。

`SHA256SUMS.txt` 用于校验附件；`third-party-sources.zip` 是对应依赖源码，普通用户无需下载。程序包不含模型、外部推理环境或用户素材；下载资源前请阅读[来源与许可说明](https://github.com/redimocteer/voxlate/blob/main/docs/RESOURCE_DOWNLOADS.md)。

## 验证与限制

本版通过自动回归、合成素材流程和打包程序启动检查；源码与发行包检查未发现本地私人路径、用户媒体或常见凭据。测试使用合成素材和模型替身，不代表实际模型内容质量已全面验证。

默认需要 NVIDIA CUDA 显卡及数十 GB 资源空间；未完成全新电脑安装、最低显存和各类长片的系统验证，请先试短片。识别、时间边界、翻译及音色仍需校对。声音与素材授权由使用者自行确认。

反馈请到 [Issues](https://github.com/redimocteer/voxlate/issues)，分享日志前删去私人路径、对白和凭据。
