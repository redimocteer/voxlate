# 第三方资源与下载选择

Voxlate 是免费分享的本地工具。源码和桌面包不包含 AI 权重、外部推理环境、独立 FFmpeg 程序或用户素材；项目不托管这些资源，也不提供模型整合包。必要的 Python／Qt 播放依赖随桌面包提供，其许可与对应源码仍由发行者按要求提供，不能通过“用户自行负责”省略。

以下下载确认、许可留存和导出说明功能已加入开发分支；已发布的 `v0.1.0-beta.1` 不会自动获得这些更新，旧版用户也应先阅读本文和上游协议。

## 自行选择

点击「一键准备」或某项「下载／安装」后，先查看列出的来源和许可。可取消不需要或不接受的项目；确认阅读后才下载所选资源。不确认不会发起下载。资源未齐备时，相应处理功能暂不可用。

也可以直接从上游获取资源，在资源设置中指定模型／环境路径；FFmpeg 和 FFprobe 可使用已有程序并配置相应路径。自行提供的版本需要自行确认兼容性及许可。程序不会替用户获取需要单独授权的资源、绕过访问限制或代为同意未知条款。

命令行准备会先列出来源并停止；阅读条款后才自行添加 `--accept-resource-terms`。该参数只表示确认本次下载，不是权利授予或合法用途证明。

## 留存与分享

- 模型许可、模型卡和固定版本来源保存在模型目录的 `licenses/`，附文件哈希；取不到有效声明时停止该项准备。IndexTTS 及辅助模型下载已固定 revision。此前已准备的资源不会被后台改动，可显式重新准备或自行补齐声明。
- 独立 FFmpeg 工具目录保留 `upstream/` 声明、文档和下载校验信息；不要只复制两个 EXE 来再分发。llama.cpp 保留完整上游压缩包内容。
