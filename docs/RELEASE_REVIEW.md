# 发布前核对记录

日期：2026-10-03。范围为 `v0.1.0-beta.4` Windows 桌面包及本次源码改动；依赖和许可范围沿用上一版。此记录不是全面法律、安全或代码原创性审计。

## 发行范围

- Windows x64 目录版 EXE，仅英文／日文 → 中文；不含 AI 模型、外部推理环境、用户媒体或视频项目。
- 提供使用说明、MIT、第三方许可、相对路径文件哈希及依赖版本记录；另附对应 Qt/PySide/Shiboken/FFmpeg 源码，普通用户无需下载源码附件。
- 保留可替换的 `_internal` 运行库目录；排除未使用的 Qt PDF 与 GPL-only 虚拟键盘插件。OpenSSL 固定来自打包 Python，避免混入开发机其他软件的 DLL。
- 不含打赏入口，不宣传无条件商用或所有代码完全原创。

## 本版检查

- 两条分支逐模块运行自动回归，覆盖分离覆盖与回滚、Windows JSON 文件占用、分句保存／取消、外部音色导入导出、所选句子翻译／配音、未配音保留原声导出及原有流程。
- 较长工作树路径触发外部媒体工具的路径限制，改用短路径合成目录后通过；Qt 界面播放超时的用例单独复核。
- 测试使用合成素材、真实媒体处理工具及模型替身；未重新进行所有大模型的内容质量评测。
- 更新 README、下载说明和五张界面示例；截图中的对白、音频和风景均为合成素材。
- 检查实际待提交文件、待推送提交历史及 Git 署名；使用公开 GitHub 身份与 noreply 邮箱。
- 从独立干净目录打包，检查实际 ZIP 文件、清单和哈希，并检查 EXE/Python 冻结归档中的私人构建路径；不直接打包日常使用的程序目录。
- 冻结程序启动、图标与语言选项检查通过；依赖版本和许可材料由发布脚本核验。
