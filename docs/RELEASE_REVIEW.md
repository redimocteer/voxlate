## 本版发行范围

- Windows x64 目录版 EXE；不含 AI 模型、GPU 推理环境、用户媒体或视频项目。
- 完整使用说明、MIT、第三方说明、随包许可、相对路径文件哈希清单和版本记录。
- 同一 Release 另提供对应 Qt/PySide/Shiboken/FFmpeg 源码附件。运行程序无需下载源码附件。

## 已完成检查

- README 开头集中提供用途、截图演示、硬件限制和准确版本下载入口；没有把合成示例截图当作真实配音效果。
- PyInstaller 改用目录模式公开分发，允许替换兼容 Qt/PySide 运行库，附有说明与原文许可。
- 排除未使用的 Qt Virtual Keyboard 与 PDF 插件及其 DLL；不把 GPL-only 虚拟键盘误带入 MIT 应用的运行包。
- 固定从打包 Python 的 DLLs 目录取 OpenSSL，避免从开发机其他软件的 PATH 混入不同版本。
- 核对随包 Qt/PySide/Shiboken 6.8.3、FFmpeg 7.1 的版本和源归档；播放器 FFmpeg 自报 LGPL 2.1-or-later，具体构建参数保存在二进制分发记录。
- 收集 Qt 模块及绑定源码中的许可、版权、NOTICE，补充 Python、OpenSSL、libffi、Mesa 与 PyInstaller 的声明。
- 源码提交扫描没有发现常见令牌、私钥和个人 Windows 用户路径。只有约 1.2 MB 的源码、测试、文档和合成示例图；未混入模型、真实媒体、构建缓存或安装包。扫描不保证排除所有秘密或溯源问题。
- beta.2 的 231 项自动测试在正常 Windows 权限下全部通过，覆盖日语模型属性检查、原文／译文单格与框选复制、复制时不改变句子状态，以及原有处理流程。测试使用合成素材与模型替身，不代表所有模型内容质量已验证。
- 本机已安装的 Whisper turbo 在日语模式下处理合成静音音频通过，确认修复后的属性调用与真实运行环境兼容；这不属于识别准确率评测。
- 冻结程序启动、资源配置、图标、OpenSSL 加载及 4 秒合成视频播放检查通过。未重新下载几十 GB 模型做全新机器全流程测试；最低硬件要求及长视频稳定性仍未系统验证。
