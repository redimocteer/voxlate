# 三语言开发版验证记录

2026-09-27，本机离线测试，使用虚构短句和 FFmpeg flite 合成的参考声；未使用用户视频、对白或真实人物音色。

## 结果

- 六个翻译方向均通过真实 Hy-MT2 7B 推理，测试语义为“早上好，请把窗户打开”。每个方向独立启动约 6–10 秒，包含模型加载。
- IndexTTS 2.5 按 `ZH`、`EN`、`JA` 生成六段有效音频。每种语言两句分别约 80、44、48 秒，包含加载；首轮冷启动占主要时间，不能据此比较语言速度。
- Whisper large-v3 回识别三种输出，分别得到“早上好，请把窗户打开”、`Good morning, please open the window.`、`おはようございます。窓を開けていただけますか。`。
- 真实 FFmpeg 导出的英、日、中配音音轨分别标记 `eng`、`jpn`、`zho`，原声音轨单独保留。
- Windows 开发版 EXE 启动检查通过，界面列出六个方向；资源准备与无 Python 新电脑安装未重测。

## 测试发现及修正

- 原单模型 Whisper 多语言检查读取了错误属性；修正为底层模型属性，并用实际中、日识别及带接口约束的替身测试验证。
- 首次一条英→日译文末尾出现多余符号；补充新方向的格式提示后，中→日、英→日共六条复测输出正常。模型仍可能出错，不能视为彻底消除格式或内容错误。
- 各方向隔离项目、输出文件、翻译与配音设置；旧中文输出缓存不因加入目标语言字段而失效。

最终完整回归 **233 项通过**，覆盖 GUI 切换／恢复、旧项目兼容、不同目标语言拒绝写入同一项目、模型参数、配音缓存、手动分句、开发版配置隔离与中文识别。

这些是基础链路验证，不是自然度或翻译质量评测。尚未进行六个方向的真实电影全流程试听；跨语言音色、日语读音和长句时长仍需人工评估。
